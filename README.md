
# 伴老友｜台灣長者生活資訊與銀髮族友善服務平台

**伴老友 Elder Companion** 一個免費以繁體中文設計的台灣高齡友善生活資訊網站，協助長輩、銀髮族、家人與照顧者，更輕鬆地查詢日常生活中的重要資訊。

透過簡單清楚的介面，整合台灣各縣市的預定停水、預定停電、天氣預報等公開資訊，減少搜尋不同政府網站的困擾。

> 讓科技更簡單，讓關心更貼近。  
> 伴老友，希望成為每位長輩日常生活中的好朋友。

## 伴老友可以做什麼？

### 💧 台灣預定停水資訊

查詢台灣各縣市的預定停水公告，了解可能受影響的地區、停水原因及預計恢復供水時間。
協助長輩提前儲水、安排用水，降低臨時停水帶來的不便。

**資料來源：** 台灣自來水公司公開資料。

### ⚡ 台灣預定停電資訊

彙整台灣電力公司的預定停電公告，提供停電地區、時間及相關資訊。
方便家人提前協助長輩安排生活，尤其是需要使用家用電器或醫療輔助設備的家庭。

**資料來源：** 台灣電力公司公開資料。

> 重要設備的供電安排，請務必再次向台電或相關服務單位確認

### 🌤️ 台灣天氣預報

整合中央氣象署的天氣預報資料，讓使用者快速了解所在地區近期的天氣狀況。
提供天氣描述、氣溫與降雨機率等資訊，協助長輩安排出門、散步、購物與日常活動。

**資料來源：** 交通部中央氣象署。

### 🚨 氣象警示資訊

系統設有氣象警示資料處理機制，持續改善官方資料來源的相容性及有效期限管理。
部分氣象警示來源可能因官方介面異動而暫時無法取得資料。
遇到颱風、豪雨、強風或其他天氣風險時，請優先查看中央氣象署最新公告：

https://www.cwa.gov.tw/

## 為什麼打造伴老友？

台灣逐漸邁入高齡社會，許多日常資訊雖然已經公開，卻散落在不同網站。
對部分長輩而言，查詢生活資訊可能遇到以下困難：

- 網站文字太小，閱讀不方便
- 資訊分散，不容易找到正確入口
- 公告內容過於複雜，難以快速理解
- 舊公告與新資訊混在一起，容易造成誤解
- 手機操作步驟太多，使用門檻較高

希望透過更清楚的資訊分類、更簡單的操作方式，以及持續更新的公開資料，讓長輩和照顧者都能更方便地取得生活資訊。

## 核心設計理念

### 👓 清楚易讀

以長者友善的閱讀與操作體驗為目標，重視文字辨識度、資訊層次與簡單的操作流程。

### 📍 在地生活

以台灣 22 縣市為資訊分類基礎，讓使用者更容易找到與自己生活地區相關的公告。

### 🔄 持續更新

透過 GitHub Actions 執行民生資訊更新程序，減少人工維護的負擔。

### 🧹 過期資訊自動淘汰

系統會依資料類型設定保留期限，避免已經結束的公告持續出現在資訊清單中。

目前資料保留原則：

| 資訊類型 | 保留原則 |
|---|---|
| 天氣預報 | 現在至未來 3 天 |
| 預定停水 | 進行中或未來 30 天 |
| 預定停電 | 進行中或未來 30 天 |
| 氣象警示 | 僅保留有效期限內的警示 |

資料來源更新失敗時，系統也會重新檢查既有公告的有效期限。

> 自動更新不代表即時更新。實際公告內容仍以主管機關發布的最新資訊為準。

## 專案技術

伴老友採用網頁技術開發，並透過 GitHub Pages 提供網站服務
目前民生資訊更新系統包含：

- Python 資料擷取與整理
- GitHub Actions 自動執行
- JSON 公告資料輸出
- 資料有效期限檢查
- 重複公告處理
- 資料來源狀態紀錄
- 來源失敗時的有效舊資料保留機制

主要資料檔案：

```text
scripts/
  update_life_data.py

data/
  life_information.json
  life_source_status.json
```

## 常見問題 FAQ

### 伴老友是什麼？

伴老友是一個免費的台灣長者友善生活資訊網站，
整合預定停水、預定停電、天氣預報等日常資訊，協助銀髮族及照顧者更容易取得重要公告。

### 伴老友需要付費嗎？

不需要。伴老友提供免費的網站使用方式。

### 伴老友需要下載 App 嗎？

不需要。使用手機、平板或電腦瀏覽器即可開啟網站。

### 可以查詢台灣哪些地區的資訊？

民生資訊資料處理系統以台灣 22 縣市為分類基礎。
實際可查詢的公告依各官方來源提供的資料而定。

### 停水停電資訊是即時的嗎？

網站會透過自動更新程序取得官方公開資料，但不保證即時同步。
重要事項請再次向台灣自來水公司或台灣電力公司確認。

### 天氣預報來自哪裡？

天氣預報資料來自交通部中央氣象署的公開資料服務。

### 伴老友是政府官方網站嗎？

不是。
伴老友是獨立開發的生活資訊整合網站，提供更方便的公開資訊閱讀入口。
